# Smart Factory For Education


## Setup

```
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```


## Run
```
(.venv) pip install --upgrade pip
(.venv) bash build.sh
(.venv) python factory.py -d <arduino_device>
```
